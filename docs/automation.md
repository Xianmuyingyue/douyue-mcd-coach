# 可选自动化：每日热量 / 板烧提醒

> 这是一个**可选的自动化**，**默认不开启**。它不会自动弹、也不会替你开启。
> 你需要时，在 WorkBuddy 的「自动化」面板**手动新建并启用**即可（或让我按你说的时间建好，等你手动启用）。

## 触发
- 每天 **12:00** 和 **18:00** 各一次（每天定点）

> 已按此在 WorkBuddy 建好**两个暂停态自动化**（中午 12:00 / 晚上 18:00），默认**关闭**、不会自动弹；你在「自动化」面板点开启才生效。

## 内容（自动化 prompt，直接粘贴）
```
读取今天的每日热量记录（在 douyue-mcd-coach 目录运行 `python scripts/daily_tracker.py show`），
用「板烧」为单位汇报：今天已记 X 板烧（约 Y kcal），目标 3.3 板烧，还差 Z 板烧。
若午餐/晚餐还没吃，推荐一个窦月法低卡套餐（板烧经典餐 / 双层吉士餐 / 麦香鱼轻食，
给出热量·蛋白·板烧），并提醒合理缺口 300–500、每周 0.5–1kg。中文，简洁，3–6 行。
```

## 数据来源
- 记录文件：`~/.workbuddy/douyue_mcd_coach/daily.json`（仅本机、不入仓库）
- 读写脚本：`python scripts/daily_tracker.py add|show`
- 单位：1 板烧 = 400 kcal；每日目标 3.3 板烧（≈1300 kcal）

## 如何手动启用
1. WorkBuddy 左侧「自动化」→ 新建；
2. 触发设为「每天 12:00 和 18:00」；
3. 粘贴上面的 prompt；
4. 保存后**由你手动开启**（默认保持暂停）。

> 提醒：这是完全可选的。不需要就放着一动不动；要用时再开。
