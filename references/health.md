# 健康护栏与免责边界（references/health.md）

本文件为 Skill 的健康护栏知识库与免责边界。所有健康判断以此为准，引用来源为公开医学科普。

## 一、窦月减肥法为何有风险（权威来源）

据长江航运总医院·武汉脑科医院内分泌代谢科副主任医师罗琼（2026-10 多家媒体报道）分析：

- 该网红食谱本质**极低热量饮食**：两个去酱板烧鸡腿堡约 700 大卡 + 白馒头约 185 大卡 + 早餐，全天仅 **900–1000 大卡**，远低于普通成年人基础代谢（1200–1600 大卡）。
- 短期快速掉秤多为**脱水 + 糖原消耗**，并非减脂（1kg 脂肪 ≈ 7700 大卡）。
- 长期坚持：基础代谢下降、"溜溜球效应"反弹、肌肉流失、便秘脱发、女性月经紊乱；晚餐纯白馒头为精制高 GI 碳水，缺蛋白 / 纤维，夜间易暴食。

## 二、改良版（Skill 推荐的"健康版窦月法"）

- 午餐：保留**去酱 / 减酱汉堡** + 加一份蔬菜（蔬菜杯）；
- 晚餐：白馒头**换粗粮馒头** + 配蔬菜与优质蛋白（鸡胸 / 豆腐）；
- 热量缺口控制在 **300–500 大卡/天**，安全减重速度 **每周 0.5–1kg**；
- 汉堡本身非"垃圾食品"，关键在酱料与搭配。

## 三、护栏规则（Skill 必须执行）

1. 每日总热量下限：女性 ≥ 1200、男性 ≥ 1500 大卡；低于下限必须提醒并上调。
2. 检测到"全天只吃白馒头 / 纯碳水、无蛋白"连续 ≥ 2 天，强制提示改良版。
3. 热量缺口 > 800 大卡/天，提示极低碳水风险。
4. 用户提及孕期、未成年、基础疾病，立即建议咨询医生 / 营养师，不给出具体饮食处方。
